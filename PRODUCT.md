## Platform

web

## Stack

Delegated: Astro (static output) with hand-written CSS and small client scripts. No UI framework runtime shipped to the browser. Chosen because the site is content-first, bilingual (EN/PL routing built in), needs top Core Web Vitals, and deploys as plain static files to Cloudflare Pages (free tier, `*.pages.dev`). Motion uses CSS and the Web Animations API; no animation library unless a specific effect needs one.

## Users

Recruiters and hiring managers filling permanent (employment) senior .NET / backend / cloud roles, in Poland and internationally. They arrive from a LinkedIn profile, a CV link, or a job application, usually on a laptop during a screening pass, sometimes on a phone. Their job: decide within a minute or two whether Adam is senior enough to put forward, then contact him.
